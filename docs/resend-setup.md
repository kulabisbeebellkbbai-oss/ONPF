# Resend SMTP for ONPF

Resend is the selected outbound provider for the ONPF AWS contact form. This guide describes configuration; it is not evidence of an installed or verified service. Follow [the existing-instance update guide](aws-contact-update.md) for backup, release installation, migration and recovery requirements.

## Account and domain

1. Sign in at [Resend](https://resend.com/login), or create a Free account and complete account verification. If the embedded browser displays a generic signup error, try a regular browser or a supported Google/GitHub sign-in. Do not repeatedly submit an unexplained failing signup.
2. Add the sending domain `notify.onpf.example.org`, with the US North Virginia region. Keep inbound receiving disabled. Copy the exact DNS records generated by Resend into the existing public `onpf.example.org` Route 53 hosted zone. Preserve the website records and any unrelated mail records.
3. Wait until Resend reports the domain verified. Configure DMARC for this sending subdomain, with no reporting recipient unless deliberately selected. Disable open and click tracking; enable enforced TLS for delivery.
4. Create a credential named `ONPF production SMTP`, with **Sending access** restricted to `notify.onpf.example.org`. Store the credential in the private password file below. A temporary administrative credential used for automated domain setup must not become the production SMTP credential; revoke it when setup finishes.

See Resend's [domain setup](https://resend.com/docs/add-a-domain), [domain features](https://resend.com/docs/dashboard/domains/introduction), and [API key permissions](https://resend.com/docs/create-an-api-key). Resend's Free account does not require a separate production approval, but domain verification is required.

## Existing AWS instance settings

Update these fields in the existing private `/etc/onpf/backup.json`, retaining its storage, backup and hostname configuration:

```json
{
  "smtp_host": "smtp.resend.com",
  "smtp_port": 587,
  "smtp_from": "contact@notify.onpf.example.org",
  "smtp_user": "resend",
  "smtp_password_file": "/etc/onpf/smtp-password"
}
```

ONPF upgrades the connection with STARTTLS before authenticating. The SMTP password is the Resend API key. Do not put it in this JSON, Git, a release bundle, a chat message, or an SSM command parameter (which AWS records). The private file must contain only the key and be readable by `onpf`, normally `0640 root:onpf`. Preserve the existing private recipient configuration.

Apply configuration using the release installer as described in the update guide. Confirm the resulting environment contains the hostname, port, sender, username and password-file path, without printing the password. These values match the [Resend SMTP documentation](https://resend.com/docs/send-with-smtp).

## Delivery and privacy verification

Submit a nonpersonal test through the public contact form, including a small image. Check the form's success state, then the corresponding Resend delivery event. Confirm mailbox receipt and open the image; provider acceptance alone does not establish inbox receipt. Exercise PNG, JPEG, GIF and WebP across the tests, the 2000-character boundary, and rejection of a non-image upload. Confirm only message type and time were added to `contact_sent_log` and that no uploaded files or message text were retained on the ONPF instance.

The selected Free plan has a daily and monthly quota; inspect current usage before testing and monitor it after launch. The website's general proxy rate limit and contact honeypot do not guarantee protection against exhausting that quota.

The no-message-storage requirement applies to the ONPF instance. Resend's Free plan retains email data for 30 days, including provider-side message content. Turning off provider message storage requires a qualifying paid plan and add-on; it is not included in this Free configuration. See [Resend security and retention](https://resend.com/security) and [message-storage options](https://resend.com/docs/knowledge-base/how-do-i-ensure-sensitive-data-isnt-stored-on-resend).
