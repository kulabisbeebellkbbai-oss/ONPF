# Public source release

ONPF 0.3.0 is distributed as a source snapshot with a new public Git history. The private development history, live deployment receipts, internal review records and implementation plans are not included. Those records describe individual installations and are not needed to develop or run ONPF.

Source, tests, fictional examples, dependency locks, licenses, launch scripts and reusable deployment tools/guides are included. Example domains use example.org; AWS resource fixtures and test credentials are fictional. Public AWS service principals and the Canonical publisher account identifier are upstream infrastructure references, not operator account details.

No live environment, participant database, private export, screenshot, backup, gateway credential, provider API key, local agent memory or Git authentication configuration belongs in this release. Optional AI drafting requires operators to configure their own private provider credentials.

Historical verification claims in reusable guides describe their original test scope. They do not establish that a new installation is secure, deployed, approved or ready to operate. Run the contribution checks and complete platform/deployment acceptance for your own installation.
